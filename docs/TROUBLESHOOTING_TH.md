# ปัญหาที่พบบ่อย — ถามและตอบ

[หน้าแรก](../README.md) · [English](TROUBLESHOOTING_EN.md) · [ติดตั้ง](INSTALL_TH.md) · [ปัญหาที่ทราบ](../KNOWN_ISSUES.md)

## หาโฟลเดอร์เกมไม่เจอ ต้องเปิดตรงไหน?

Steam → Library → คลิกขวาเกม → Properties… → Installed Files → Browse… แล้วหา **Behind the Frame.exe** อาจต้องเปิด BehindTheFrame_PC_Steam อีกชั้น อย่าใช้โฟลเดอร์ชื่อเกมที่สร้างขึ้นเอง ถ้าไม่พบ EXE ให้หยุดตรวจตำแหน่งก่อน

## แตก ZIP แล้วไม่เห็นไฟล์มอด?

ตรวจว่าเลือก ZIP **มอดไทย** ไม่ใช่ ZIP BepInEx คลิกขวา → Extract All… → Extract แล้วเปิดโฟลเดอร์ที่แตกจริง ถ้าเห็นโฟลเดอร์ชื่อแพ็ก ให้เปิดอีกชั้นจนเห็น README และ BepInEx ถ้าโปรแกรมป้องกันไวรัสแจ้งเตือน อย่าปิดการป้องกันหรือกู้ไฟล์โดยเดา ให้เก็บชื่อไฟล์/ข้อความเตือนและตรวจที่มาของ ZIP กับ TA Font

## มี BepInEx/BepInEx ซ้อนกัน ทำอย่างไร?

ปิดเกม ตรวจผังในคู่มือติดตั้งก่อน ไฟล์ควรอยู่ที่ `BepInEx/plugins/BehindTheFrameThai.Diagnostics.dll` ข้าง EXE ไม่ใช่ `BepInEx/BepInEx/plugins` สำรองโฟลเดอร์ที่วางผิดไว้นอกเกม แล้วคัดลอก **เฉพาะไฟล์ของมอดไทย** ไปตำแหน่งที่ถูกตาม ownership list อย่าลากทั้งโฟลเดอร์ทับหากมีมอดอื่น และอย่าลบไฟล์ที่ไม่ทราบเจ้าของ

## เกมเปิดได้ แต่ไม่มีภาษาไทยให้เลือก?

ตรวจตำแหน่ง EXE และไฟล์มอดตามผัง ต้องมี BepInEx รุ่น IL2CPP-win-x64 be.788, DLL มอดเพียงหนึ่งรุ่น, tamolly_font.bundle และ CSV ครบ เปิดครั้งแรกอาจใช้เวลาสร้างไฟล์ จากนั้นดู Settings → Language อีกครั้ง ถ้ายังไม่ขึ้น เก็บ `BepInEx/LogOutput.log` และ `ErrorLog.log` หากมี ก่อนเปิดเกมรอบใหม่ ไม่ลบเซฟเพื่อแก้

## ภาษาไทยเป็นสี่เหลี่ยม หรือวรรณยุกต์ผิดตำแหน่ง?

ปิดเกม ตรวจว่าคัดลอก tamolly_font.bundle และ DLL จากชุดเดียวกันครบ ไม่ต้องลงฟอนต์ใน Windows ใช้ Config ที่อนุมัติซึ่งเปิด ThaiLegacyShaper/ThaiFontScaling หากเคยแก้ค่า ให้เก็บสำเนาไว้ก่อนขอคำแนะนำ อย่าแก้ TTF, เซฟทับภาพ หรือผสมไฟล์คนละรุ่น

## จะลงมอดรุ่นใหม่ทับรุ่นเก่าได้เลยไหม?

ให้ [สำรองทั้งชุด](BACKUP_UNINSTALL_TH.md) ก่อน ปิดเกม ตรวจรายการไฟล์ของมอด แล้วแทนที่เฉพาะมอดไทย ไม่เก็บ DLL สำรองใน plugins และไม่ลบมอดอื่น Config เดิมต้องมีสำเนาก่อนตัดสินใจใช้ค่าชุดใหม่

## เกมเปิดไม่ได้หลังติดตั้ง BepInEx?

หยุดลองซ้ำ เก็บข้อความเตือน/Log ที่มี ตรวจว่าเป็น **6.0.0-be.788 Unity.IL2CPP-win-x64** และ winhttp.dll อยู่ข้าง EXE อย่าใช้ Latest, Mono หรือ x86 แทน หากเพิ่งทับ loader ที่มีอยู่ ให้ขอคำแนะนำพร้อมรายการไฟล์และสำเนาก่อนติดตั้ง ไม่สุ่มลบ winhttp.dll/ไฟล์เกม ไม่รีเซตเซฟ ไม่แก้ Steam Cloud และไม่ปิดโปรแกรมป้องกันไวรัสแบบเดาสุ่ม

## อยากกลับไปเล่นภาษาอังกฤษ?

เลือก Settings → Language → English ได้โดยไม่ถอนมอด ถ้าต้องการถอนด้วย ให้ทำ [คู่มือถอนมอด](BACKUP_UNINSTALL_TH.md) หลังเลือก English และปิดเกม ถ้าเข้าเมนูไม่ได้ให้ขอคำแนะนำ ไม่แก้ภาษาใน saveData.txt

## มีภาพอังกฤษบางรายการ หรือ Cinema แปลไม่ครบ?

ระบบเดิมใช้ English fallback เมื่อภาพไทยไม่มี/ไม่ผ่านเงื่อนไข ตรวจว่าครบ 34 ภาพและ Cinema 12 เฟรม ชื่อและไบต์ต้องตรงกับชุดที่ได้รับ อย่าเปิดแล้วเซฟทับ PNG เลือกภาษาก่อนเข้า Cinema; การสลับกลางภาพเคลื่อนไหวยังไม่ผ่าน QA

## กลับเมนูแล้วเข้าเล่นบทเดิม ภาพดำแต่ยังมีเสียง?

อาจเป็น [ปัญหาที่ทราบ](../KNOWN_ISSUES.md) **หลังหน้าหมายเลขบทเมื่อควรเข้าฉากเล่น** ไม่ใช่พื้นดำปกติช่วง Loading/ชื่อบท ลองปิดเกมแล้วเปิดใหม่ก่อนเข้าอีกครั้งอาจช่วยได้ แต่ไม่รับประกัน ไม่บังคับรีโหลดฉาก/ล้าง cache/ลบเซฟตามการเดา ESC แว๊บและ Chapter6/Continue เป็นคนละประเด็น ถ้า Continue ผิดปกติให้หยุดเส้นทางนั้นและรายงาน

## ส่งข้อมูลอะไรให้ TA Font?

แจ้งรุ่นแพ็ก/ปลั๊กอิน ภาษาที่เลือก บท/ขั้นตอน เส้นทางที่กด ผลภาพ เสียงและเมาส์ พร้อมภาพหน้าจอ/Log ที่ตรวจข้อมูลส่วนตัวแล้ว เก็บ Log ก่อนเปิดเกมใหม่ ไม่ส่ง Save, Cloud หรือข้อมูลบัญชีโดยไม่จำเป็น [รายงานปัญหาหรือข้อกังวลด้านสิทธิ์](https://github.com/IsAmArt/Behind-the-Frame-The-Finest-Scenery---MOD-Thai/issues)
