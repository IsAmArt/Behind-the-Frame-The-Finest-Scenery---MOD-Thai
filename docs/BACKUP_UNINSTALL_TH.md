# สำรอง อัปเดต ถอน และย้อนกลับ

[หน้าแรก](../README.md) · [English](BACKUP_UNINSTALL_EN.md) · [ติดตั้ง](INSTALL_TH.md)

## 1. สำรองมอดรุ่นเก่า

1. ปิดเกม เปิดโฟลเดอร์เกมตามคู่มือติดตั้ง
2. สร้างโฟลเดอร์ใหม่ **นอกโฟลเดอร์เกม** เช่น `Documents/BehindTheFrameThai_Backup/รุ่นเดิม/` อย่าเก็บ DLL สำรองใน `BepInEx/plugins`
3. ในโฟลเดอร์เกม คัดลอกรายการต่อไปนี้ไป Backup โดยรักษาลำดับโฟลเดอร์ ใช้ **Copy / คัดลอก** และ **Paste / วาง** ไม่ต้องย้ายหรือลบเซฟ:

```text
BepInEx/plugins/BehindTheFrameThai.Diagnostics.dll
BepInEx/plugins/tamolly_font.bundle
BepInEx/plugins/BehindTheFrameThai/                 ← คัดลอกทั้งโฟลเดอร์คำแปลและภาพ
BepInEx/config/dev.modthai.behindtheframe.diagnostics.cfg
```

4. ตรวจว่ามีครบ **DLL + Font Bundle + Localization/Artwork + Config** เป็นชุดเดียวกัน เก็บ ZIP/เลขรุ่น/รายการ Hash ของรุ่นเก่าไว้ด้วย
5. ถ้าเคยมี BepInEx/มอดอื่นอยู่ก่อน ให้สำรองไฟล์ loader/config เดิมแยกต่างหากก่อนเปลี่ยนรุ่น ไม่ใช้รายการมอดไทยเป็นสิทธิ์ลบไฟล์ร่วม

## 2. อัปเดตมอดไทย

หลังสำรองแล้ว ปิดเกม แตก ZIP ใหม่ข้างนอกเกม ตรวจรายการ [ไฟล์ของมอด](../release/FILE_OWNERSHIP.json) และคัดลอกเฉพาะ BepInEx ของชุดใหม่ไปตำแหน่งเดิม ยืนยันแทนที่เฉพาะไฟล์มอดไทยที่ตั้งใจอัปเดต ไม่วาง DLL หลายรุ่นและไม่ทับไฟล์มอดอื่น หากมี Config ของตัวเอง ให้เก็บสำเนาก่อนและตรวจค่าที่ต้องการรักษา อย่าผสม DLL/CSV/ภาพจากคนละชุดด้วยการเดา

## 3. ถอนเฉพาะมอดภาษาไทย

1. ถ้าเข้าเมนูได้ เลือก **Settings → Language → English** ก่อน แล้วปิดเกม ถ้าเข้าไม่ได้ ให้หยุดและขอคำแนะนำ ไม่แก้ข้อความในเซฟ
2. สำรอง DLL + Bundle + Localization/Artwork + Config รุ่นปัจจุบันเป็นชุดตามข้อ1ข้างบนก่อนย้ายไฟล์
3. เปิด **FILE_OWNERSHIP.json ของรุ่นที่ติดตั้ง** ด้วย Notepad หรือเว็บเบราว์เซอร์ ดู `relative_install_path` ซึ่งเป็นตำแหน่งไฟล์นับจากโฟลเดอร์ที่มี EXE รายการเป็นไฟล์ของมอด ไม่ใช่คำสั่งให้รัน
4. เปิด File Explorer แล้วสร้างโฟลเดอร์พักไว้นอกเกม เช่น `BehindTheFrameThai_Removed` ย้ายเฉพาะไฟล์ที่ตรงรายการและยืนยันว่าเป็นของมอดนี้ไปเก็บไว้ก่อน หากไม่แน่ใจหรือไฟล์ถูกแก้ ให้เก็บสำเนาและสอบถาม
5. รายการหลักคือ DLL, Font Bundle, ไฟล์คำแปล/ภาพใต้ BehindTheFrameThai และ Config ของมอดตามผังข้างบน ถ้ามีไฟล์อื่นในโฟลเดอร์เดียวกัน อย่าย้ายรวมไปด้วย
6. **ห้ามลบทั้ง BepInEx/plugins** และอย่าลบ BepInEx, `winhttp.dll` หรือ Config ที่มอดอื่นใช้ การถอน BepInEx เป็นเรื่องแยก ต้องตรวจเจ้าของไฟล์ก่อน
7. **ห้ามลบ แก้ ย้าย หรือกู้ทับ Save/Steam Cloud** เพื่อถอนมอด ไม่ต้องเริ่ม New Game

8. ผู้ใช้เปิดเกมตรวจผลด้วยตนเอง หากผิดปกติให้หยุด ไม่กู้ทับเซฟตามการเดา

## 4. ย้อนกลับรุ่นเดิม

ปิดเกม ย้ายไฟล์เฉพาะมอดรุ่นใหม่ออกตาม ownership list แล้วคัดลอก **ทั้งชุด DLL + Bundle + Data + Config ของรุ่นเดิม** กลับตำแหน่งเดิม เก็บมอดเพียงหนึ่งรุ่น หากภาษา บทที่ปลดล็อก หรือความคืบหน้าต่างไป ให้หยุดและรายงาน ไม่รีเซต/กู้เซฟเองเพื่อแก้ การถอนหรือย้อนรุ่นไม่ได้รับรองว่าปัญหาจอดำหรือ ESC จะหาย


## 5. กลับ Vanilla ที่ไม่มี BepInEx — เฉพาะกรณียืนยันเจ้าของไฟล์แล้ว

ถ้ามีมอดอื่นหรือไม่รู้ที่มาของ loader **หยุดก่อน อย่าย้าย BepInEx ที่ใช้ร่วมกัน** การถอนเฉพาะมอดไทยในข้อ3ยังคง BepInExอยู่ ไม่ใช่ Vanilla แบบไม่มีloader

1. ถ้าเข้าเมนูได้ เลือก English แล้วปิดเกมและ Launcher ทุกตัว เก็บสำรองมอดปัจจุบันและไฟล์ก่อนติดตั้งไว้นอกเกม
2. ตรวจรายการติดตั้ง/ZIP BepInEx เดิมและสำเนาก่อนติดตั้งให้ยืนยันว่า loader และแต่ละส่วนเป็นของที่เพิ่ม **สำหรับมอดนี้เท่านั้น** ไม่ใช่ไฟล์เกมเดิม/ของมอดอื่น/ชุด.NETที่โปรแกรมอื่นใช้ หากยืนยันไม่ได้ให้สอบถามก่อน
3. รุ่นที่กำหนด be.788 มี root entries: `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `changelog.txt`, `BepInEx/`, `dotnet/` เป็นข้อมูลเทียบต้นทาง **ไม่ใช่คำสั่งย้ายทุกไฟล์ชื่อนี้** โดยเฉพาะ changelog.txt/โฟลเดอร์ทั่วไปอาจมีเจ้าของอื่น ส่วน cache/interop/log ที่สร้างใต้ BepInExอยู่ในโฟลเดอร์นั้น
4. ใช้ File Explorer สร้างโฟลเดอร์พัก **นอกเกม** คัดลอกสำรองก่อน แล้วย้ายออกเฉพาะ entries ที่ยืนยันตรงกับ BepInExที่ลงไว้สำหรับมอดนี้จริง รวม root loader **winhttp.dll** ที่ยืนยันแล้ว ถ้าเคยทับไฟล์ที่มีอยู่ก่อน ให้หยุดใช้แผนนี้และขอแผนคืนต้นฉบับ ไม่เดาว่าย้ายออกได้ทั้งหมด ไม่มีสคริปต์ลบอัตโนมัติ
5. ตรวจว่าไม่มีเส้นทางโหลด BepInExอื่น/ตัวเลือกเปิดเกมที่เคยเพิ่มไว้ หากไม่ทราบให้หยุดตรวจ ไม่เปลี่ยนlaunchoptionsหรือไฟล์อื่นโดยเดา การไม่เห็น consoleอย่างเดียวไม่ยืนยันVanilla; ดูว่าไม่มีstartupLogใหม่ของloaderประกอบ ไม่ลบLogเก่าเพื่อทำหลักฐาน
6. หากจำเป็น ให้เปิด Steam → Library → คลิกขวาเกม → Properties… → Installed Files → **Verify integrity of game files** หลังนำส่วนประกอบที่ยืนยันแล้วออก Verifyอาจคืนไฟล์เกมที่ขาด/เปลี่ยน แต่ **ไม่ควรคาดว่าจะลบไฟล์third-partyที่เพิ่มมาทั้งหมด** จึงไม่แทนขั้นตอนตรวจloaderข้างต้น
7. ผู้ใช้เปิดเกมเองตรวจว่าเข้าเมนูได้ ถ้ายังดำตั้งแต่เปิด ดู [คู่มือstartup](STARTUP_BLACK_SCREEN_TH.md) อย่าลบSave/Cloudหรือแก้Registryอัตโนมัติ การกลับVanillaไม่รับประกันว่าปัญหาเข้าบทเดิมซ้ำจะหาย

ไม่ย้ายเกมEXE, GameAssembly.dll, UnityPlayer.dll, `_Data`, Save/LocalLow หรือSteamCloudตามรายการBepInEx ไม่ใช้Registryresetเป็นขั้นตอนถอนมอด
