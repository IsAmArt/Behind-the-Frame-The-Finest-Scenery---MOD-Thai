# สำรอง อัปเดต ถอน และย้อนกลับ

[หน้าแรก](../README.md) · [English](BACKUP_UNINSTALL_EN.md) · [ติดตั้ง](INSTALL_TH.md)

## 1. สำรองมอดรุ่นเก่า

1. ปิดเกม เปิดโฟลเดอร์เกมตามคู่มือติดตั้ง
2. สร้างโฟลเดอร์ใหม่ **นอกโฟลเดอร์เกม** เช่น `Documents/BehindTheFrameThai_Backup/รุ่นเดิม/` อย่าเก็บ DLL สำรองใน `BepInEx/plugins`
3. ในโฟลเดอร์เกม คัดลอกรายการต่อไปนี้ไป Backup โดยรักษาลำดับโฟลเดอร์ ใช้ **Copy / คัดลอก** และ **Paste / วาง** ไม่ต้องย้ายหรือลบเซฟ:

```text
BepInEx/plugins/BehindTheFrameThai.Diagnostics.dll
BepInEx/plugins/tamolly_font.bundle
BepInEx/plugins/BehindTheFrameThai/                 ← คัดลอกทั้งโฟลเดอร์คำแปลและภาพ
BepInEx/config/dev.modthai.behindtheframe.diagnostics.cfg
```

4. ตรวจว่ามีครบ **DLL + Font Bundle + Localization/Artwork + Config** เป็นชุดเดียวกัน เก็บ ZIP/เลขรุ่น/รายการ Hash ของรุ่นเก่าไว้ด้วย
5. ถ้าเคยมี BepInEx/มอดอื่นอยู่ก่อน ให้สำรองไฟล์ loader/config เดิมแยกต่างหากก่อนเปลี่ยนรุ่น ไม่ใช้รายการมอดไทยเป็นสิทธิ์ลบไฟล์ร่วม

## 2. อัปเดตมอดไทย

หลังสำรองแล้ว ปิดเกม แตก ZIP ใหม่ข้างนอกเกม ตรวจรายการ [ไฟล์ของมอด](../release/FILE_OWNERSHIP.json) และคัดลอกเฉพาะ BepInEx ของชุดใหม่ไปตำแหน่งเดิม ยืนยันแทนที่เฉพาะไฟล์มอดไทยที่ตั้งใจอัปเดต ไม่วาง DLL หลายรุ่นและไม่ทับไฟล์มอดอื่น หากมี Config ของตัวเอง ให้เก็บสำเนาก่อนและตรวจค่าที่ต้องการรักษา อย่าผสม DLL/CSV/ภาพจากคนละชุดด้วยการเดา

## 3. ถอนเฉพาะมอดภาษาไทย

1. ถ้าเข้าเมนูได้ เลือก **Settings → Language → English** ก่อน แล้วปิดเกม ถ้าเข้าไม่ได้ ให้หยุดและขอคำแนะนำ ไม่แก้ข้อความในเซฟ
2. เปิด **FILE_OWNERSHIP.json ของรุ่นที่ติดตั้ง** ด้วย Notepad หรือเว็บเบราว์เซอร์ ดู `relative_install_path` ซึ่งเป็นตำแหน่งไฟล์นับจากโฟลเดอร์ที่มี EXE รายการเป็นไฟล์ของมอด ไม่ใช่คำสั่งให้รัน
3. เปิด File Explorer แล้วสร้างโฟลเดอร์พักไว้นอกเกม เช่น `BehindTheFrameThai_Removed` ย้ายเฉพาะไฟล์ที่ตรงรายการและยืนยันว่าเป็นของมอดนี้ไปเก็บไว้ก่อน หากไม่แน่ใจหรือไฟล์ถูกแก้ ให้เก็บสำเนาและสอบถาม
4. รายการหลักคือ DLL, Font Bundle, ไฟล์คำแปล/ภาพใต้ BehindTheFrameThai และ Config ของมอดตามผังข้างบน ถ้ามีไฟล์อื่นในโฟลเดอร์เดียวกัน อย่าย้ายรวมไปด้วย
5. **ห้ามลบทั้ง BepInEx/plugins** และอย่าลบ BepInEx, `winhttp.dll` หรือ Config ที่มอดอื่นใช้ การถอน BepInEx เป็นเรื่องแยก ต้องตรวจเจ้าของไฟล์ก่อน
6. **ห้ามลบ แก้ ย้าย หรือกู้ทับ Save/Steam Cloud** เพื่อถอนมอด ไม่ต้องเริ่ม New Game

## 4. ย้อนกลับรุ่นเดิม

ปิดเกม ย้ายไฟล์เฉพาะมอดรุ่นใหม่ออกตาม ownership list แล้วคัดลอก **ทั้งชุด DLL + Bundle + Data + Config ของรุ่นเดิม** กลับตำแหน่งเดิม เก็บมอดเพียงหนึ่งรุ่น หากภาษา บทที่ปลดล็อก หรือความคืบหน้าต่างไป ให้หยุดและรายงาน ไม่รีเซต/กู้เซฟเองเพื่อแก้ การถอนหรือย้อนรุ่นไม่ได้รับรองว่าปัญหาจอดำหรือ ESC จะหาย
