# คำถามที่พบบ่อย

[หน้าแรก](../README.md)

## ต้องดาวน์โหลดทั้งสองปุ่มไหม?

ต้องมี BepInEx รุ่นที่กำหนดและ ZIP มอดไทยแยกกัน ปุ่ม BepInEx ไปยังไฟล์ทางการ ส่วนปุ่มมอดไปยัง ZIP ใน GitHub Releases ไม่ใช้ Source code ZIP แทนไฟล์มอด

## ต้องเริ่มเกมใหม่หรือลบ save ไหม?

ไม่ใช่ขั้นตอนติดตั้ง ไม่ให้ลบ/reset/edit save หรือ Steam Cloud ใช้ route ที่มีอยู่ตามที่ผู้ใช้อนุมัติ

## ทำไม package1.0.0-rc1 แต่ DLL0.7.21?

packageเป็นรุ่นชุดแจก ส่วนDLLคง functional baseline ที่ตรวจไว้ ไม่ได้ build ใหม่ Dataใช้Phase05H+QA06และภาพล่าสุด

## ทำไมชื่อ DLL มี Diagnostics?

คงชื่อ/GUIDเดิมเพื่อไม่สร้าง pluginซ้ำหรือ configแยก AllDevelopment flags=false ไม่ได้เพิ่ม debug build ใหม่

## ต้องติดตั้งฟอนต์ใน Windows หรือมี .NET SDK ไหม?

ไม่ต้องติดตั้ง TTF/SDK/Python/Unity Editor สำหรับเล่น ตัวbundleมีTAMollyฝังอยู่ และBepInExทางการมีruntimeตามชุดของมัน
Worasaitได้รับเครดิตในงานภาพบางส่วน แต่ไม่แจกfontbinaryแยกในแพ็ก

## ใช้ Steam/Epic หรือแพลตฟอร์มอื่นได้ไหม?

**ทดสอบใช้งานเบื้องต้นสำเร็จทั้ง Steam และ Epic Games Store บน Windows x64 โดยผู้จัดทำ** (31ตุลาคม2026) ทั้งVanilla, BepInExรุ่นที่กำหนดและเลือกภาษาไทยผ่าน เป็นผลเบื้องต้น ไม่ครบทุกบท/ทุกbuild ไม่กล่าวว่าbinaryสองร้านเหมือนกัน Linux/macOS/Proton/SteamDeck/VRและร้านอื่นยังไม่ได้รับรอง คำแนะนำVP8ของผู้จัดจำหน่ายบนSteamDeckไม่เท่ากับผลQAมอด

## เปิด BepInEx ครั้งแรกแล้วเห็นหน้าต่างดำ/ข้อความสีเหลือง?

นั่นอาจเป็นBepInEx consoleที่กำลังสร้างไฟล์Unity IL2CPP ยังไม่ใช่การลงมอดไทย อย่าปิดขณะมีความคืบหน้า รอเมนูเกมจริงแล้วปิดเกม จึงลงมอด สีเหลืองที่ผู้จัดทำเห็นไม่ใช่เงื่อนไขผ่านทุกเครื่อง ถ้ามีerrorให้เก็บข้อความและLog [คู่มือเปิดครั้งแรก](INSTALL_TH.md)

## มอดนี้แก้จอดำ/ESCไหม? เลือกบทอื่นคั่นช่วยแน่นอนหรือไม่?

ไม่อ้างว่าแก้แล้ว A→B→Aเคยสำเร็จแต่ไม่รับรองทุกครั้ง สาเหตุยังUNKNOWN ดูKnownIssues

## เอาภาพ/คำแปลไปแจกต่อหรือใช้เชิงพาณิชย์ได้ไหม?

ยังไม่อนุมัติสิทธิ์สาธารณะ/นำไปใช้ต่อทั้งชุด ภาพ31รายการมีส่วนเกมเดิมหรือยังไม่เคลียร์ที่มา
สิทธิ์ฟอนต์ โค้ด คำแปล ภาพ และdependencyแยกกัน ไม่ใช่แพ็กMIT/OFL/publicdomainฟรีทุกกรณี
