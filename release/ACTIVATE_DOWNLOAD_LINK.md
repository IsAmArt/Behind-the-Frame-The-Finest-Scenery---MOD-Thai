# Download-link verification

DOWNLOAD_LINKS.json records the actual repository, tag and release-asset URL once retrieved from GitHub. Both READMEs use that real ZIP asset, not Source code or private review material. The uploaded bytes must be downloaded back and hash-verified before publication is reported successful. The ZIP hash is external; changed archive contents require new checksums and verification.

Rights approval and gameplay QA flags remain false unless independently confirmed. Owner publication authorization does not grant game-rightsholder permission. This release is a pre-release, not fully certified stable.
