# Behind the Frame — Thai Localization v1.0.0-rc1 (Full Thai Mod)

**Full Content — Public Pre-release** · มอดแปลโดยแฟนเกม แจกฟรี โดย **TA Font**

## เนื้อหาครบในชุดเดียว

- คำแปล703รายการ พร้อม Phase05H + QA06
- TAMolly และระบบจัดวางสระ–วรรณยุกต์ไทย
- ภาพสมุด/จดหมายไทย34รายการ รวม AmberLetter ล่าสุด
- Cinemaไทย3ชุด/12เฟรม; English fallback เดิม
- ไฟล์ที่ใช้เล่นรวมConfig50ไฟล์; Plugin0.7.21เดิม ไม่ได้Buildใหม่

## ก่อนติดตั้ง

เคยทดสอบเฉพาะ Steam / Windows x64 / Unity IL2CPP2019.4.18f1 ใช้ BepInEx6.0.0-be.788 Unity.IL2CPP-win-x64 แยกต่างหาก ไม่ใช่ Mono/x86/BepInEx5 ไม่รวมเกม/BepInEx/ฟอนต์TTFในZIPนี้ Epicไม่รองรับ/ไม่มีQA; ผู้ใช้รายงานเกมEpicเดิมยังเปิดไม่ได้ ไม่รับรองร้านหรือแพลตฟอร์มอื่น

ดาวน์โหลด ZIPมอดจาก Assets (ไม่ใช่ Source code) แตกไฟล์ ปิดเกม สำรองมอดเก่า แล้วคัดลอก BepInExของมอดไปโฟลเดอร์ที่มี Behind the Frame.exe อย่าให้ BepInEx/BepInExซ้อน เปิดผ่านSteam → Settings → Language → ไทย ไม่ลบ/แก้SaveหรือSteamCloud

## ปัญหาที่ทราบ / ข้อจำกัดQA

เข้าบทเดิมซ้ำหลังกลับเมนูโดยยังไม่ปิดเกม อาจแสดงเลขบทแล้วดำเมื่อเข้าฉากทั้งที่ยังมีเสียง/เมาส์ ลองปิดแล้วเปิดเกมใหม่อาจช่วยแต่ไม่รับประกัน เคยเกิดขณะปิดมอด/เส้นทางloaderด้วย สาเหตุUNKNOWN ไม่อ้างว่าแก้แล้ว ESCครั้งแรกอาจแว๊บหาย ครั้งถัดไปใช้ได้ในผลที่สังเกต; ประวัติChapter6/Continueยังเป็นเรื่องแยก

เนื้อหาไทยครบไม่ได้แปลว่าQAผ่านครบ: ผู้ใช้เคยรายงานเล่นจบและไทยโดยรวมใช้งานได้ แต่ ZIPเผยแพร่ใหม่นี้ยังไม่ได้รับรองGameplayQAครบทุกจุด ไม่ใช่Stableที่รับรองแล้ว
